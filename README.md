## День 1 — Getting started, Library

Раздел: https://playwright.dev/python/docs/library (блоки «Usage» и «First script»)

Файлы:

- `day1/copied_example.py` — пример из раздела «Usage» без изменений.
- `day1/modified_example.py` — модифицированная версия.
- `day1/run.log` — вывод обоих запусков.

Что делает код: поднимает драйвер Playwright, запускает Chromium, открывает
`https://playwright.dev`, печатает заголовок страницы, закрывает браузер.

Модификация (~25% строк):

1. Добавлено `page.wait_for_load_state("load")` — заголовок читается только
   после полной загрузки страницы.
2. `print(page.title())` заменён на `assert "Playwright" in title` — скрипт
   проверяет результат, а не просто печатает его.
3. Браузер закрывается в `finally` — процесс Chromium не останется висеть,
   даже если проверка упала.

Зачем: исходный пример демонстрационный. Модифицированный вариант ведёт себя
как тест: проверяет ожидаемый результат и не оставляет мусорных процессов.
